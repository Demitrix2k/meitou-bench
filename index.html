Meitou daily benchmarks

Meitou is a C#/.NET Vulkan reimplementation of the game Kenshi (upstream: VlcekM/MeitouClient). After each upstream master update, one fixed benchmark is run (by the maintainer, and by contributors on their own machines) and its numbers are added here, next to a list of what changed upstream since the previous benchmarked commit. Lower is better for every metric.

Setup

Fixed for every run, so numbers from different days are comparable.

Build
Native Linux build of upstream master
Game data
Clean, unmodded game data (GOG copy)
Save
The same frozen save every run: two player bases; never played or saved over
Graphics
Full settings
Measurement
MangoHud frame-time logging; frame metrics come from the game's bench frames
Machines
The maintainer's laptop and machines of contributors; see "Machines" below
Run by
The maintainer after each upstream master update; contributors with the dev kit in kit/

Two scenarios are run: the play benchmark is upstream's own --play-bench (camera segments idle, orbit, zoom, pan); the base switch jumps the camera four times between the two bases. "Slow-world tick" is the game's own timing of its slowest simulation ticks.

Runs and series

Within one commit and scenario, runs are numbered by time: run 1, run 2. They are never averaged together; run 1 is drawn as a filled circle, run 2 as a hollow diamond.

    Series break lines on the charts mark where the procedure changed, so a jump across one may come from the procedure rather than from the code. Cache-cold run 1 in series 2 is the closest match to series 1's single runs.

    Machines

    Who ran the benchmark, on what. Contributors submit results by pull request (see CONTRIBUTING.md in the repository); the handle links to their GitHub profile.

    Coverage

    Compare two commits

    Pick any two benchmarked commits. Lower is better for every metric. The selection is kept in the page address, so a comparison can be linked.

    Changes between benchmarks

    Newest first. Summaries are taken from upstream commit messages only, not reviewed. Areas are guessed from the part of the subject before the colon; anything unrecognised is listed as Other.
